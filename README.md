# Ритм — мини-приложение для Telegram-бота

Визуализация задач, календаря и финансов, которые ведёт n8n-агент Cossmo.
Открывается как Telegram Mini App внутри бота.

**Живая версия:** https://hanzosalomandar01-alt.github.io/finance-tg-miniappp/

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | само приложение — один файл, его и раздаёт GitHub Pages |
| [`n8n/`](n8n/) | серверная часть: воркфлоу n8n, код нод и инструкция по настройке |

Начни с [`n8n/README.md`](n8n/README.md) — там настройка по шагам и разбор,
как всё устроено.

## Коротко об устройстве

    Мини-приложение ──POST──► n8n (webhook)
                                  ├─ Google Tasks     → задачи
                                  ├─ Google Calendar  → события
                                  └─ Google Sheets    → финансы

Данные живут в Google, приложение их только отображает и отмечает задачи
выполненными. Настройки — в блоке `window.RITM_CONFIG` в начале `index.html`.

## Безопасность

Запросы к n8n подписаны механизмом Telegram `initData`, поэтому приложение
работает **только внутри Telegram** — в обычном браузере оно покажет «нет связи».

Токен бота хранится только в n8n и в этом репозитории отсутствует. Не добавляй
его сюда: он даёт полный контроль над ботом.
