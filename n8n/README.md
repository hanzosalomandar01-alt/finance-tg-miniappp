# Синхронизация мини-приложения «Ритм» с n8n

Мини-приложение перестаёт быть демо и показывает реальные задачи, события
и финансы, которые ведёт агент Cossmo.

## Как это работает

Воркфлоу Cossmo (Telegram → Switch → агент → Google Tasks/Calendar/Sheets)
**не меняется вообще**. Рядом появляется второй, read-only:

    Мини-приложение ──POST──► Webhook ──► Config
                                            │
                                            ├─ Google Tasks     → задачи
                                            ├─ Google Calendar  → события
                                            ├─ Google Sheets    → лист «Транзакции» (опционально)
                                            ├─ Свод (raw)       → лист «Свод»: Доход / Расход
                                            │
                                            └─ Normalize ──► JSON ──► приложение

Google остаётся единственным источником правды. Приложение подтягивает данные
при открытии, при возврате из фона, раз в 60 секунд и по кнопке в шапке.

## Откуда берутся финансы

Переключатель `financeSource` в `index.html`:

| Значение | Что показывает | Что берётся из таблицы |
|---|---|---|
| `"svod"` (сейчас) | Доходы, Расходы, Баланс и подпись месяца | две цифры из листа **«Свод»** |
| `"transactions"` | то же + фильтры периодов, расходы по категориям, список операций | построчно из листа **«Транзакции»** |

В режиме `svod` фильтры периодов и блок операций скрываются — в двух итоговых
числах их просто нет. Чтобы переключиться, поменяй одно слово в `index.html`,
n8n трогать не нужно: он отдаёт и то, и другое.

Парсер «Свода» ищет ячейки со словами «Доход» и «Расход» по всему листу и берёт
ближайшее число под ними (или справа). Раскладка с твоего скриншота —
подпись месяца в строке 2, заголовки в строке 3, суммы в строке 4 — читается
как есть; перестановка строк или колонок её не сломает.

## Файлы

| Файл | Что это |
|---|---|
| `n8n-miniapp-api.json` | Воркфлоу чтения: задачи, события, финансы |
| `n8n-miniapp-action.json` | Воркфлоу записи: отметка задач выполненными |
| `action-auth.js` | Код Code-ноды «Auth» из воркфлоу записи |
| `normalize.js` | Код Code-ноды (уже внутри JSON, здесь — для чтения и правок) |
| `auth-hmac.js` | Необязательно: строгая проверка подписи Telegram |
| `index.html` | Пропатченное приложение — заменить им файл в GitHub-репозитории |
| `original.html` | Исходная версия, если нужно откатиться |

## Настройка: 7 шагов

### 1. Импортировать воркфлоу
В n8n: **Workflows → ⋯ → Import from File** → `n8n-miniapp-api.json`.

### 2. Подключить креденшелы
Выбрать те же аккаунты Google, что уже стоят в Cossmo, в четырёх нодах:
**Google Tasks**, **Google Calendar**, **Google Sheets** и **Свод (raw)**.

У ноды «Свод (raw)» это HTTP Request: тип авторизации уже выставлен на
*Predefined Credential Type → Google Sheets OAuth2 API*, нужно только выбрать
сам аккаунт. Если у тебя сервисный аккаунт, а не OAuth2 — поменяй тип
на *Google API* и выбери его.

### 3. Указать ID таблицы
Открыть ноду **Config** и вписать в поле `sheetId` ID таблицы «Бюджет Т1»
(из URL: `docs.google.com/spreadsheets/d/`**`ЭТА_ЧАСТЬ`**`/edit`).
Он задаётся один раз здесь и подставляется во все остальные ноды.

Поле `svodRange` — диапазон листа со сводом, по умолчанию `Свод!A1:Z200`.
Менять нужно только если лист назван иначе.

### 4. Задать секрет
В ноде **Normalize** (первые строки) заменить `ПОМЕНЯЙ_НА_СВОЙ_СЕКРЕТ`
на любую длинную случайную строку.

### 5. Активировать и скопировать URL
Включить воркфлоу тумблером **Active**, открыть ноду **Webhook** и скопировать
**Production URL** — вида `https://твой-n8n/webhook/miniapp-data`.

### 6. Прописать URL в приложении
В `index.html`, в блоке `window.RITM_CONFIG` в самом верху:

```js
window.RITM_CONFIG = {
  apiUrl:         "https://твой-n8n/webhook/miniapp-data",
  apiToken:       "тот_же_секрет_что_в_Normalize",
  autoRefreshSec: 60,
  actionUrl:      "https://твой-n8n/webhook/miniapp-action",
  financeSource:  "svod"
};
```

### 7. Залить в репозиторий
Заменить `index.html` в `hanzosalomandar01-alt/finance-tg-miniappp` и закоммитить.
GitHub Pages обновится за минуту-две.

## Отметка задач выполненными

Само по себе приложение только читает данные: галочка меняет состояние лишь
в браузере и слетает при следующей синхронизации. Второй воркфлоу это чинит.

**Установка:**

1. Импортировать `n8n-miniapp-action.json` как отдельный воркфлоу
2. В ноде **Google Tasks** выбрать тот же аккаунт Google
3. В ноде **Auth** вписать **тот же секрет**, что в Normalize и в `index.html`
4. Включить тумблер **Active**
5. Скопировать Production URL и положить в `actionUrl` в `index.html`

Путь вебхука — `miniapp-action`, с `miniapp-data` он не конфликтует, так что оба
воркфлоу спокойно работают одновременно.

**Как ведёт себя приложение.** Отметка применяется мгновенно, запись в Google идёт
фоном. Если сервер не принял — галочка откатывается обратно, а в шапке загорается
«не сохранилось», чтобы ты не считал задачу закрытой, когда это не так.

**Что будет с задачей дальше** — зависит от опции **Show Hidden** в ноде Google Tasks
воркфлоу чтения:

| Show Hidden | Поведение после отметки |
|---|---|
| **выключена** | задача исчезает из приложения совсем |
| включена | остаётся зачёркнутой, видна под фильтром «Выполненные» |

## Проверка

* Индикатор под датой в шапке: зелёный «обновлено 14:32» — всё хорошо,
  красный — нет связи, серый «демо-режим» — `apiUrl` ещё не заполнен.
* Если цифры не те — в n8n открыть **Executions** воркфлоу MiniApp API и посмотреть
  выход ноды **Normalize**: там есть `totals` (что прочиталось из «Свода») и
  `counts.svodRows` (сколько строк листа пришло). `svodRows: 0` — не тот диапазон
  или нет доступа; `totals: null` — лист пустой.
* Ответ `unauthorized` — секрет в `index.html` и в ноде Normalize не совпадают.

## Тонкости

**Список задач.** Нода Google Tasks читает список `@default`. Если Cossmo пишет
в другой список, поменяй значение поля в ноде.

**Приоритеты.** В Google Tasks нет поля приоритета, поэтому он выводится из текста:
`!!` или слова «срочно / важно / высокий» → высокий, «низкий / потом» → низкий,
иначе средний. Чтобы это работало, добавь в системный промпт Cossmo строку вроде:
«для срочных задач добавляй `!!` в конец названия».

**Календарь.** Читается календарь `primary`, окно −30 / +180 дней от сегодня.
Меняется в ноде Google Calendar.

**Мгновенность.** Данные приходят при каждом открытии приложения, так что после
команды боту достаточно открыть мини-приложение — оно уже актуально. Если хочется
совсем бесшовно, в конце воркфлоу Cossmo можно слать сообщение с кнопкой-`web_app`.

## Про безопасность: подпись Telegram

Раньше единственной защитой был `apiToken`, а он лежит в открытом виде в исходнике
публичной страницы на GitHub Pages. С появлением воркфлоу записи это стало опасно:
эндпоинт не только отдаёт данные, но и меняет задачи в Google.

Теперь оба воркфлоу проверяют **подпись Telegram** (`initData`). Telegram подписывает
её ключом, выведенным из токена бота, поэтому подделать запрос, не зная токена,
невозможно. Проверяется всё сразу: подлинность подписи, что данные не подменили
после подписания, и что подписи не больше 24 часов.

### Что нужно вписать

В обоих воркфлоу — в ноде **Normalize** (чтение) и в ноде **Auth** (запись) — заменить
в первых строках:

```js
const BOT_TOKEN = 'ВСТАВЬ_ТОКЕН_БОТА';
```

на токен бота от @BotFather — тот же, что в Telegram-креденшеле n8n.

**Токен бота вписывается только в n8n. Никогда не коммить его в git и не класть
в `index.html`** — он даёт полный контроль над ботом.

### Важное следствие

После включения подписи **приложение работает только внутри Telegram**. Если открыть
сайт в обычном браузере, `initData` там нет, и в шапке будет «нет связи» — это
правильное поведение, а не поломка.

### Ограничить доступ только своим аккаунтом

По умолчанию пройдёт любой, кто открыл мини-приложение твоего бота. Если бот только
твой — этого достаточно. Чтобы сузить до конкретного аккаунта, впиши свой Telegram ID:

```js
const ALLOWED_TG_IDS = [123456789];
```

Узнать свой ID можно у бота @userinfobot.

### Диагностика

При отказе эндпоинт возвращает конкретную причину — по ней сразу видно, что не так:

| Ответ | Что означает |
|---|---|
| `bot token not set` | `BOT_TOKEN` не заменён на настоящий |
| `crypto unavailable` | в этой установке n8n недоступен модуль `crypto` |
| `no initData` | запрос не из Telegram (например, из браузера) |
| `bad signature` | подпись не сходится — не тот токен бота |
| `expired` | приложение открыто больше 24 часов назад, нужно переоткрыть |
| `forbidden` | Telegram ID не входит в `ALLOWED_TG_IDS` |
